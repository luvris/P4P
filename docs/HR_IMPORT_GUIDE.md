# คำแนะนำการ Import ข้อมูลบุคลากร

## ✅ อัปเดตเมื่อ: 2026-09-25

ระบบได้รับการปรับปรุงให้รองรับการ import ข้อมูลแบบรวม (ข้อมูลส่วนตัว + ประวัติการทำงาน) ในแถวเดียวกันแล้ว

## 🎯 ฟิลด์สำคัญที่จะถูกแปลงอัตโนมัติ

### 1. **EMPLOYEE** (คอลัมน์ที่ 24)
- **ข้อมูล:** ประเภทบุคลากร
- **ตัวอย่าง:** "ข้าราชการ", "พนักงานราชการ", "ลูกจ้าง", "พนักงานกระทรวง"
- **การทำงาน:** 
  - ระบบจะแปลงเป็น `employee_type_id` อัตโนมัติ
  - ถ้าไม่มีในระบบ จะสร้างใหม่ทันที
  - อัพเดตให้ตาราง `employees.employee_type_id`

### 2. **POSITION** (คอลัมน์ที่ 27)
- **ข้อมูล:** ตำแหน่งงาน
- **ตัวอย่าง:** "พยาบาลวิชาชีพ", "นายแพทย์", "นักจัดการงานทั่วไป"
- **การทำงาน:**
  - ระบบจะแปลงเป็น `position_id` อัตโนมัติ
  - ถ้าไม่มีในระบบ จะสร้างใหม่ทันที
  - อัพเดตให้ตาราง `employees.position_id`

### 3. **STATUS** (คอลัมน์ที่ 16)
- **ข้อมูล:** สถานะการทำงาน
- **ตัวอย่าง:** "ทำงาน", "ปฏิบัติงานอยู่", "ลาออก"
- **การทำงาน:**
  - ระบบจะแปลงเป็น `status_id`
  - ถ้าไม่มี จะใช้ค่า default: "ปฏิบัติงานอยู่"

## 🚀 ขั้นตอนการ Import

### 1. เตรียมไฟล์ Excel
- ตรวจสอบว่า header ตรงตามรูปแบบข้างต้น
- ข้อมูลเริ่มจากบรรทัดที่ 2
- บันทึกเป็น `.xlsx` หรือ `.xls`

### 2. เข้าสู่หน้า Import
- เข้าเมนู **"นำเข้าข้อมูลบุคลากร"** (HR Import)
- URL: `/hr/import`

### 3. Upload ไฟล์
1. คลิก **"เลือกไฟล์"** แล้วเลือกไฟล์ Excel
2. ระบบจะแสดง **Preview** ข้อมูล 10 แถวแรก
3. ตรวจสอบความถูกต้อง

### 4. ยืนยันการ Import
- คลิกปุ่ม **"ยืนยันการนำเข้า"**
- รอระบบประมวลผล (อาจใช้เวลา 1-2 นาที สำหรับข้อมูลหลายร้อยแถว)

### 5. ตรวจสอบผลลัพธ์
- ระบบจะแสดงสรุปผล:
  - จำนวนที่เพิ่มใหม่ (Inserted)
  - จำนวนที่อัพเดต (Updated)
  - จำนวนที่ข้าม (Skipped)
  - รายการที่มีข้อผิดพลาด (Errors)

---

## ✨ การทำงานของระบบ

### ขั้นตอนที่ 1: Import ข้อมูลส่วนตัว
- ใช้ **HID (เลขบัตรประชาชน)** เป็น Key
- ถ้ามีอยู่แล้ว → **อัพเดต**
- ถ้าไม่มี → **สร้างใหม่**

### ขั้นตอนที่ 2: Import ประวัติการทำงาน
- ใช้ **PID + SER** เป็น Key
- เก็บลง `employment_histories`
- แปลง **EMPLOYEE** → `employee_type_id`
- แปลง **POSITION** → `position_id`

### ขั้นตอนที่ 3: อัพเดต Employee
- อัพเดต `employee_type_id` และ `position_id` ให้ `employees` table
- ใช้ข้อมูลจากแต่ละแถว (ไม่ใช่แค่ล่าสุด)

---

## ⚠️ ข้อควรระวัง

1. **เลขบัตรประชาชน (HID)**
   - ต้องมี 13 หลัก
   - ใช้เป็น Key หลักในการ upsert

2. **PID (Employee ID)**
   - ต้องตรงกันระหว่างข้อมูลส่วนตัวและประวัติ
   - ใช้เชื่อมโยงข้อมูล

3. **ประเภทบุคลากรและตำแหน่ง**
   - ต้องสะกดให้ถูกต้องตรงกัน
   - ระบบจะสร้างใหม่ถ้าไม่มี (อาจทำให้มีรายการซ้ำถ้าสะกดผิด)
   - ตัวอย่าง: "ข้าราชการ" ≠ "ข้าราชการ " (มีช่องว่างท้าย)

4. **ข้อมูลซ้ำ**
   - ระบบจะ update แทนการสร้างใหม่
   - ไม่ต้องกังวลเรื่องข้อมูลซ้ำ

---

## 📊 ผลลัพธ์หลัง Import

### ✅ ข้อมูลที่จะอัพเดต:
1. **ตาราง `employees`**
   - ข้อมูลส่วนตัวทั้งหมด
   - `employee_type_id` ← จาก EMPLOYEE
   - `position_id` ← จาก POSITION
   - `status_id` ← จาก STATUS

2. **ตาราง `employment_histories`**
   - ประวัติการทำงานทั้งหมด
   - เก็บข้อความ position เดิมไว้ด้วย

3. **ตาราง `positions`**
   - เพิ่มตำแหน่งใหม่อัตโนมัติ (ถ้ายังไม่มี)

4. **ตาราง `employee_types`**
   - เพิ่มประเภทใหม่อัตโนมัติ (ถ้ายังไม่มี)

### 🎯 ผลลัพธ์ในหน้ารายชื่อบุคลากร:
- แสดงข้อมูลครบทุกคอลัมน์:
  - ✅ ชื่อ-นามสกุล
  - ✅ ประเภท (จาก EMPLOYEE)
  - ✅ ตำแหน่ง (จาก POSITION)
  - ✅ ภารกิจ
  - ✅ สถานะ (จาก STATUS)

## 🛠️ แก้ปัญหา

### ปัญหา: ข้อมูลไม่แสดง
- **สาเหตุ:** ไฟล์ไม่มีคอลัมน์ EMPLOYEE หรือ POSITION
- **แก้ไข:** ตรวจสอบ header ให้ตรงตามรูปแบบ

### ปัญหา: Import ล้มเหลว
- **สาเหตุ:** เลขบัตรประชาชนไม่ครบ 13 หลัก
- **แก้ไข:** ตรวจสอบคอลัมน์ HID

### ปัญหา: ตำแหน่งซ้ำกัน
- **สาเหตุ:** สะกดชื่อไม่เหมือนกัน (ช่องว่าง, ตัวพิมพ์)
- **แก้ไข:** ทำ data cleaning ก่อน import
