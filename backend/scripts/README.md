# สคริปต์ช่วยตรวจสอบ (Backend Scripts)

> 🔒 สคริปต์เหล่านี้พิมพ์ข้อมูลจริงออกทางหน้าจอ — ห้ามแนบผลลัพธ์ (ที่มีชื่อ เลขบัตรประชาชน
> เลขที่บัญชี เงินเดือน) ไปยังเอกสาร, issue หรือ commit ลง Git

สคริปต์ PHP สำหรับ debug / ตรวจสอบข้อมูลบนเครื่องนักพัฒนา **ไม่ได้เป็นส่วนหนึ่งของระบบที่รันบนเซิร์ฟเวอร์**
ทั้งหมดรันจากโฟลเดอร์ `backend/` ด้วย `php scripts/<ชื่อไฟล์>.php`
(สคริปต์บางตัวต้องเพิ่ม memory: `php -d memory_limit=1024M scripts/test_all_files.php`)

| สคริปต์ | ใช้ทำอะไร |
| --- | --- |
| `check_imports.php` | สรุปประวัติการนำเข้าล่าสุด 5 รายการ + จำนวนแถวใน `employees` / `payrolls` / ยอดรายรับรวม |
| `test_all_files.php` | ลองอ่านไฟล์ที่อยู่ใน `storage/app/private/imports` ล่าสุด 5 ไฟล์ ด้วย `NewFormatPayrollParser` พร้อมสรุปจำนวนแถวต่องวด — **ต้องใช้ `-d memory_limit=1024M`** เพราะอ่านหลายไฟล์ในกระบวนการเดียวกัน |
| `make_sample_payroll.php` | สร้างไฟล์ตัวอย่างรูปแบบใหม่ (39 คอลัมน์, 5 คน) ไว้ที่ `backend/sample_payroll_new_format.xlsx` สำหรับทดลอง import ด้วยมือ |

> สคริปต์ที่เคยอยู่ที่ราก `backend/` (`analyze_db.php`, `analyze_excel.php`, `inspect_import.php`)
> ถูกลบแล้วเนื่องจากผูกกับ flow รูปแบบเก่า ใช้พาธไฟล์ที่ตายตัว และบางตัวพิมพ์ข้อมูลบุคคลจริง
> ฟังก์ชันเหล่านี้ครอบคลุมด้วย `check_imports.php` + `test_all_files.php` แล้ว

## ข้อควรระวัง

- สคริปต์เหล่านี้เชื่อมต่อฐานข้อมูลตามค่าใน `.env` ของเครื่องนั้น
  **ห้ามรันบนเซิร์ฟเวอร์จริง**
- ตัวอย่าง**จำนวนแถว**ที่ถูกต้องหลังนำเข้าไฟล์จริง (2,673 แถว = 8 งวด × ~349 คน):
  `Payrolls: 2673`, `Employees with position: 349` — เป็นเพียงยอดรวม ไม่ใช่ข้อมูลรายบุคคร
